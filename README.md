## 🌟 Главный проект

### [🧠 MoodLens Lab](https://github.com/daesnoo/moodlens-lab)

Локальное WPF-приложение для учебного распознавания эмоционального тона сообщений. Оно работает без входа в Telegram и без отправки данных в интернет.

- 💬 анализирует текстовые сообщения;
- 😊 определяет шесть эмоциональных категорий;
- 📥 импортирует обезличенные CSV, TXT, JSON и HTML;
- 🔒 обрабатывает данные только на компьютере.
